CalmRoute

CalmRoute este canalul lui Rareș Mureșan, șofer de ridesharing din Cluj-Napoca: transmisiuni live cu drumuri prin oraș, însoțite de muzică, și videoclipuri scurte pentru șoferi și pasageri.

Lumi — asistentul din chat-ul live

Lumi este o aplicație folosită numai pe canalul YouTube CalmRoute. În timpul transmisiunilor live citește mesajele din chat și poate răspunde scurt la întrebări și saluturi. Răspunsurile sunt marcate cu „🤖 Lumi” și sunt generate de un model AI care rulează local, pe calculatorul lui Rareș.

CalmRoute Publisher — statistici și publicare

CalmRoute Publisher este o unealtă locală folosită numai pentru conturile lui Rareș: citește statisticile canalului YouTube CalmRoute și publică videoclipuri scurte pe YouTube (CalmRoute) și Instagram (@calmroutedrive), prin interfețele oficiale ale platformelor.

Ambele aplicații folosesc YouTube API Services. Nu sunt aplicații publice: nu pot fi folosite de alte persoane pentru conturile lor.

Politica de confidențialitate · Termeni de utilizare

In English

CalmRoute is the YouTube channel of Rareș Mureșan, a ride-hailing driver in Cluj-Napoca, Romania. Lumi is a live-chat assistant used only on the CalmRoute channel; it reads live chat messages and posts short replies marked “🤖 Lumi”, generated by an AI model running locally. CalmRoute Publisher is a private tool that reads the CalmRoute channel's statistics and publishes short videos to Rareș's own YouTube and Instagram accounts. Both use YouTube API Services.
